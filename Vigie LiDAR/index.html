      Réaction du porteur : marche droit devant.

      • Impulsions de plus en plus rapides en approchant : obstacle au sol.
      • Double impulsion : obstacle en hauteur, que la canne ne touche pas.
      • Vibration longue : marche, trou ou bordure.

      Le côté qui vibre indique où est le danger. Un danger juste devant fait vibrer les deux côtés.

      Quand les lunettes parlent : d’elles-mêmes, seulement en cas d’urgence : objet rapide qui coupe la route (vélo, trottinette), obstacle à hauteur de visage, vide sur la trajectoire. Ce que la canne trouve seule (bornes, bancs, marches) n’est pas annoncé, pas plus qu’un piéton : il nous voit et s’écarte. Pour une description, le porteur demande : bouton en haut à droite de la scène ou touche Q.

      Comment le LiDAR classe un point

      Avec la distance, l'angle du rayon et l'inclinaison de la tête (lue par une IMU), on calcule la hauteur du point par rapport au sol sous les pieds.

      < −10 cm sous les pieds : marche ou trou
      −10 à 10 cmle sol, ignoré
      10 cm à 1,25 m obstacle au sol
      1,25 à 2,1 m hauteur de tête (si rien en dessous)
      > 2,1 mau-dessus, ignoré

      La chaîne complète

      1. Capter. La caméra donne une image, le LiDAR une liste de distances.
      2. Reconnaître. Le modèle de la caméra encadre les objets connus.
      3. Mesurer. Chaque mesure du LiDAR devient un point 3D avec une hauteur, puis une classe (tableau ci-dessus).
      4. Fusionner. Les points LiDAR qui tombent dans le cadre d'un objet reconnu lui donnent sa distance exacte.
      5. Décider. Pour chaque secteur (gauche, devant, droite), on garde le danger le plus proche.
      6. Prévenir. Intensité selon la distance (2,5 m → 0,6 m), motif selon le type de danger.

      Code Python simplifié (Raspberry Pi)

      # 1. LiDAR : distances -> vibreurs
import math
ALERTE, CRITIQUE = 2.5, 0.6          # mètres

def classer(h):
    if h < -0.10: return "descente"
    if h <= 0.10: return "sol"
    if h <= 1.25: return "obstacle"
    if h <= 2.10: return "tete"
    return "au-dessus"

def trame_vers_vibreurs(dist, azim, elev, tangage, h_capteur=1.65):
    # dist en m (None = pas de retour), angles en radians,
    # tangage = inclinaison de la tête lue sur l'IMU
    proche = {"G": 99, "C": 99, "D": 99}
    for d, az, el in zip(dist, azim, elev):
        if d is None: continue
        a = el + tangage
        h  = h_capteur + d * math.sin(a)   # hauteur du point
        dh = d * math.cos(a)               # distance au sol
        if classer(h) in ("obstacle", "tete", "descente"):
            s = "G" if az < -0.26 else "D" if az > 0.26 else "C"
            proche[s] = min(proche[s], dh)
    i = {s: max(0, min(1, (ALERTE - d) / (ALERTE - CRITIQUE)))
         for s, d in proche.items()}
    return max(i["G"], i["C"]), max(i["D"], i["C"])

# 2. Fusion : nommer les objets avec la caméra,
#    les mesurer avec le LiDAR
def fusion(detections, points):
    # detections : [(nom, x0, y0, x1, y1)] cadres dans l'image
    # points : [(u, v, distance)] points LiDAR projetés dans l'image
    # (il faut calibrer caméra et LiDAR l'un par rapport à l'autre)
    objets = []
    for nom, x0, y0, x1, y1 in detections:
        d = [p[2] for p in points
             if x0 <= p[0] <= x1 and y0 <= p[1] <= y1]
        objets.append((nom, min(d) if d else None))
    return objets
